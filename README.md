# 开源阅读书源检测

> 简洁、安静的书源助手：批量导入开源阅读（Legado）书源，自动联网检测可用性，再把可用的书源重新导出。

**说明：** 本项目由 AI 创作

---

## 📢 发布公告

**v0.1.13** 已发布（试验版）：

- 应用改名「书源助手」；
- 界面改为简洁平淡的白底低饱和风格；
- 启动图标同步换新，跟随浅色/单色系统主题；
- 导入 → 检测 → 导出可用书源全流程可用；
- 支持标准检测（按书源搜索规则发真实搜索请求）与快速检测（仅站点连通性）。
- 新增独立「生成书源」页面：输入网站首页 / 搜索页，自动推断搜索地址与列表规则，生成 Legado JSON，可加入检测列表继续体检。
- 新增「适性预检」：先判断网站能否自动做成书源，给出“可直接生成 / 需人工补规则 / 暂不适合”及具体原因。
- 新增可保存的「运行日志」页面：记录导入、检测、生成与导出过程，可导出到手机任意位置。
- 导出书源支持「保存到文件夹」，可自定义存储位置（Android 系统文件选择器）。
- 新增书源分组：导入时自动识别 小说 / 漫画 / 成人 / 音频 / 其他，支持分组筛选、手动改分组、按分组导出。
- 导入支持多选文件合并，也可反复追加导入；配合分组导出可把多个书源文件合成一个分类书源文件。
- 列表支持多选管理：长按进入多选，可全选当前筛选、批量删除。
- 成人内容合并为统一「成人」分组：明确成人线索与疑似成人线索都会归入。
- 检测支持「内容识别成人」：不只根据名称/分组文字判断，还会分析实际抓到的站点/搜索页面正文特征，命中后自动归入「成人」并在详情里注明命中词。
- 批量检测支持暂停/继续：检测中可随时暂停，暂停后仍可继续或彻底停止。
- 修复底部操作按钮在检测/暂停时切换造成的错位，布局保持固定对齐。
- 修复成人内容误判：不再把 Telegram/敏感资源等站群通用标签视为成人；内容识别改为强特征命中一次或弱特征多次才判定。
- 成人识别强制走「主动访问」：检测时抓取站点/搜索页面正文判断，不只看标题；可在开始检测前填写自定义关键词（逗号/换行分隔），命中任意关键词即归入成人并注明命中词。
- 底部「导入 / 开始 / 停止 / 导出」改为固定四按钮等宽布局，运行、暂停、空闲时不再隐藏或跳动。
- 自检修复：检测运行中导出按钮保持禁用，检测结束才恢复；运行状态与列表统计统一刷新。
- 底部四按钮改为短文字（开始/暂停/继续/停止），全部同一行等宽显示，不再挤压或显示不全。

## ✨ 功能

- **导入**：粘贴书源 JSON，或选择 `.json` / `.txt` 文件
- **网址生成（试验，独立页面）**：输入网址 → 自动抓取页面并推断搜索地址和列表规则 → 生成书源初稿
- **批量检测**
  - 快速：检查书源站点/接口是否可达，重复域名自动去重
  - 标准：可达性之外，尽量按 `searchUrl` 规则发出真实搜索请求
- **检测状态**：可用 / 疑似可用（需登录、反爬或含 JS 规则未深检）/ 失效
- **导出**：按“仅可用 / 可用 + 疑似 / 失效”导出，格式与导入时一致，可直接导入开源阅读 App
- 检测在通知栏后台持续运行，锁屏不中断

## 📱 使用

1. 打开 App，点击“导入”，选择书源 JSON 或粘贴内容；
2. 也可以点击主页右上角“生成书源”进入独立页面，输入小说站网址生成书源初稿；
3. 点击“开始检测”，等待进度完成；
4. 点击“导出”，选择要保留的状态并分享保存；
5. 将导出的 JSON 用开源阅读的“导入书源”功能重新导入即可。

## 🛠 技术说明

- 独立 Android 应用，Kotlin 编写
- 保留书源原始 JSON 字段，导出不丢数据
- 内置兼容 Legado 常见写法的搜索规则解析：GET / POST、`{{key}}` 替换、charset、header 等
- 含 `@js:` / `<js>` / WebView 的规则自动降级为站点连通性检测，并标记为“疑似可用”
