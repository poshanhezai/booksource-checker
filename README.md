# 开源阅读书源检测

> 简洁、安静的阅读工具：书架、搜索、目录、正文阅读，同时内置书源管理能力，可导入、检测、分类、去重和导出 Legado 书源。

**说明：** 本项目由 AI 创作

---

## ✨ 功能

- **书架阅读**：搜索书籍 → 查看详情/目录 → 分章阅读，支持章节切换、字号调整、夜间模式、阅读进度保存
- **阅读搜索**：选择一个已导入书源，按书名/作者搜索，并可直接进入阅读
- **书源管理**：批量导入、网络导入、多文件合并、书源去重、自动分类（小说/漫画/成人/音频/其他）
- **导入**：粘贴书源 JSON，或选择 `.json` / `.txt` 文件
- **书源去重**：按“相同地址 + 相同名称 / 完全相同 JSON”清理重复书源，保留第一份
- **网址生成（试验，独立页面）**：输入网址 → 自动抓取页面并推断搜索地址和列表规则 → 生成书源初稿
- **批量检测**
  - 快速：检查书源站点/接口是否可达，重复域名自动去重
  - 标准：可达性之外，尽量按 `searchUrl` 规则发出真实搜索请求
- **检测状态**：可用 / 疑似可用（需登录、反爬或含 JS 规则未深检）/ 失效
- **导出**：按“仅可用 / 可用 + 疑似 / 失效”导出，格式与导入时一致，可直接导入开源阅读 App
- **红米 / HyperOS 兼容模式**：应用内检测，绕过系统对后台前台服务的限制；小米/红米机型默认勾选
- **运行日志**：记录设备信息、检测参数、每个失败书源的原因、内容识别命中、前台服务/网络异常和完整崩溃堆栈，可导出保存
- 检测在通知栏后台持续运行，锁屏不中断

## 📱 使用

1. 打开 App 先进入“书架”；
2. 第一次使用点右上角“书源”，导入书源 JSON 并检测可用性；
3. 回到书架点“搜索”，选择书源后输入书名/作者；
4. 点搜索结果进入详情，点“加入书架”或“开始阅读”；
5. 阅读页支持目录、上一章/下一章、字号和夜间模式；
6. 在书源管理页可分组筛选、批量删除、去重，并按分类或整体导出书源。

## 🛠 技术说明

- 独立 Android 应用，Kotlin 编写
- 保留书源原始 JSON 字段，导出不丢数据
- 内置自主实现的 Legado 规则解析：HTML 链式规则 / CSS / XPath / JSONPath，支持 `##正则##替换##`
- 内置兼容 Legado 常见写法的搜索规则解析：GET / POST、`{{key}}` 替换、charset、header 等
- 含 `@js:` / `<js>` / WebView 的规则自动降级为站点连通性检测，并标记为“疑似可用”

## 🏗 构建

```bash
gradlew.bat :app:assembleDebug
```

需要 JDK 17、Android SDK（compileSdk 35）。APK 输出在：
`app/build/outputs/apk/debug/app-debug.apk`
